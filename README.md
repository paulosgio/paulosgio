### 📋 List Users

Aplicação para gerenciamento de usuários e listas, desenvolvida com foco em organização de código, POO e arquitetura em camadas.

**Tecnologias:** Node.js • TypeScript • Express • Prisma • PostgreSQL • React • Docker

### 📧 Newsletter

Projeto inspirado em plataformas de newsletter, desenvolvido para estudar **mensageria e processamento assíncrono**.

**Tecnologias:** Node.js • TypeScript • Express • Prisma • PostgreSQL • RabbitMQ • Docker

A arquitetura utiliza um **worker separado** para processar o envio de e-mails através de uma fila.
